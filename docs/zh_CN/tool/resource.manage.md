# 管理 GO/KEGG 资源包

`resource.manage` · 富集 · v1.0.0

## 一句话说明

列出、导入并启用带版本的本地 GO/KEGG 资源包，供富集任务使用。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 对表达矩阵或功能注释做探索性统计，生成可继续绘图和人工审核的结果表。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`GO OBO`、`Gene-GO TSV`、`Gene-pathway TSV`
- 该工具没有必填参数；仍应确认数据集、路径和运行环境。
- 确认输入格式、ID、表头和坐标约定与参数描述一致，并保留原始文件。

## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `action` 操作 | 否 | LIST | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 LIST 列出资源包；IMPORT_GO/IMPORT_KEGG 导入不可变资源包；ACTIVATE 切换当前启用包。 |
| `kind` 列表过滤 | 否 | ALL | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 把 LIST 限制为 GO、KEGG 或全部资源包。 |
| `id` 资源包 ID | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 导入时可选的稳定 ID，或要启用的资源包 ID。 |
| `name` 资源包名称 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 导入资源包的显示名称。 |
| `version` 资源包版本 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 版本标签，例如 go-basic-2026-11；留空时使用导入日期。 |
| `obo` GO OBO 文件 | 否 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 供 go.level 和资源包元数据使用的 GO OBO 1.4 文件。 |
| `annotations` Gene-GO 注释 | 否 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 两列：基因与 GO term；从资源包运行 GO 富集时需要。 |
| `mapping` 基因-通路映射 | 否 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 两列：基因与 KEGG 通路 ID。 |
| `pathwayNames` 通路名称 | 否 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 可选的通路/名称两列表，用于 KEGG 结果说明。 |
| `activate` 导入后启用 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 把新资源包设为该类别的当前启用包，替换旧的活动包。 |

## 结果怎么读

- 输出格式：`TSV`、`JSON`
- 结果取决于所选输入和参数；检查输出文件、摘要指标和诊断信息是否与实验设计一致。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run resource.manage
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 格式、列名、坐标或资源版本不匹配时，任务会在发布输出前失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
