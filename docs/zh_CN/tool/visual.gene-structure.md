# 基因结构图

`visual.gene-structure` · 可视化 · v1.0.0

## 一句话说明

将选中的 GFF3/GTF 基因绘制为转录本和 feature 结构图。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 把已经校验的数值表转换为用于检查或发表的图像，同时保留可追踪的数据路径。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`GFF3`、`GTF`、`GFF3.gz`、`GTF.gz`
- 必须提供：`input`
- 确认表头、数值列和缺失值符合参数要求；先检查输入表，再为图像解释负责。

### 格式示意

```text
##gff-version 3
chr1	OpenTools	gene	1	100	.	+	.	ID=gene1
chr1	OpenTools	mRNA	1	100	.	+	.	ID=tx1;Parent=gene1
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入注释 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 GFF3 或 GTF 注释文件，可选用 gzip 压缩。 |
| `geneIds` 基因 ID | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选基因 ID，可使用换行、逗号或分号分隔。 |
| `featureTypes` Feature 类型 | 否 | exon,CDS | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 转录本轨道中绘制的 feature 类型，逗号分隔。 |
| `maxGenes` 最大基因数 | 否 | 20 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 图形中最多包含的基因位点数。 |
| `title` 图标题 | 否 | Gene structures | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选的图形模型标题。 |
| `subtitle` 图副标题 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选的图形模型副标题。 |
| `width` 图像宽度 | 否 | 1200 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 以像素计的导出宽度。 |
| `height` 图像高度 | 否 | 800 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 以像素计的导出高度。 |
| `dpi` PDF DPI | 否 | 144 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 记录在图形导出参数中的分辨率。 |
| `exportFormats` 导出格式 | 否 | PNG_SVG_PDF | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 选择 PNG、SVG 和 PDF 产物。 |
| `exportData` 导出 feature 坐标 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 将当前绘制的 feature 坐标写为 TSV。 |
| `output` 输出前缀 | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 图形模型和图像输出的可选基础路径。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有的自定义输出文件。 |

## 结果怎么读

- 输出格式：`SVG`、`PNG`、`PDF`、`JSON`
- 图展示所选基因的转录本与外显子/CDS 结构；先确认代表转录本和坐标范围，再比较异构体。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。
- 若输出了数据表，应同时核对图中点、组别、排序和筛选是否与数据一致。

## 最小运行示例

```powershell
opentools run visual.gene-structure --param input=C:\data\input.gff3
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 空数据、全为缺失值、非数值列或阈值两侧没有数据时，图可能为空或无法解释。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
