# 过滤 FASTA

`fasta.filter` · 序列 · v1.1.0

## 一句话说明

流式过滤 FASTA，支持 ID、正则表达式、长度、GC 和 N 比例。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 在组装、注释、比对或下游分析前检查、转换或整理 FASTA/FASTQ 数据。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`FASTA`、`FASTA.gz`
- 必须提供：`input`
- 确认序列 ID 不重复、FASTA/FASTQ 记录完整；gzip 文件应保持原始记录格式。

### 格式示意

**input**

```text
>seq1
ATGCGTACGT
>seq2
ATGCGTTCGT
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入 FASTA | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 FASTA 文件，可选用 gzip 压缩。 |
| `threads` 线程数 | 否 | 0 | 大文件保留 `0` 自动选择；需要固定顺序或小文件时可用 `1`。 0 对大型文件自动选择；1 关闭并行记录处理。 |
| `includeIds` 保留 ID | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选 ID，用空白、逗号或分号分隔；留空时保留全部 ID。 |
| `excludeIds` 排除 ID | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选 ID，用空白、逗号或分号分隔。 |
| `includeRegex` 保留 ID 正则 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选的 Java 正则表达式；ID 中包含匹配内容时保留记录。 |
| `excludeRegex` 排除 ID 正则 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选的 Java 正则表达式；ID 匹配时过滤该记录。 |
| `ignoreCase` 忽略 ID 大小写 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 ID 与正则匹配不区分大小写。 |
| `minLength` 最小长度 | 否 | 0 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 允许的最小序列长度，包含边界值。 |
| `maxLength` 最大长度 | 否 | 2147483647 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 允许的最大序列长度，包含边界值。 |
| `minGcPercent` 最小 GC 百分比 | 否 | 0.0 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 最小 GC 百分比；GC 按 A/C/G/T/U 碱基数计算。 |
| `maxGcPercent` 最大 GC 百分比 | 否 | 100.0 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 最大 GC 百分比；GC 按 A/C/G/T/U 碱基数计算。 |
| `minNPercent` 最小 N 百分比 | 否 | 0.0 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 按全部序列字符计算的最小 N 百分比。 |
| `maxNPercent` 最大 N 百分比 | 否 | 100.0 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 按全部序列字符计算的最大 N 百分比。 |
| `output` 输出 FASTA | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录；.gz 后缀启用 gzip 输出。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有的自定义输出文件。 |

## 结果怎么读

- 输出格式：`FASTA`、`FASTA.gz`、`TSV report`
- 输出保留满足全部筛选条件的记录，报告解释每条被过滤的原因；阈值变化应记录在运行参数中。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。
- 线程数只影响执行路径和速度；改变线程不应改变科学结果。发现差异时应比较日志、输入和参数。

## 最小运行示例

```powershell
opentools run fasta.filter --param input=C:\data\input.fasta
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- FASTA/FASTQ 记录、ID 和碱基/质量字符必须完整；损坏或截断的记录会使任务失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
