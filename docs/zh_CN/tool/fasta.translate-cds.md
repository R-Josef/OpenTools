# CDS 翻译为蛋白

`fasta.translate-cds` · 序列 · v1.2.0

## 一句话说明

使用可配置 NCBI 遗传密码表将核酸 FASTA 翻译为蛋白。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 在组装、注释、比对或下游分析前检查、转换或整理 FASTA/FASTQ 数据。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`FASTA`、`FASTA.gz`
- 必须提供：`input`
- 确认序列 ID 不重复、FASTA/FASTQ 记录完整；gzip 文件应保持原始记录格式。

### 格式示意

**input**

```text
>seq1
ATGCGTACGT
>seq2
ATGCGTTCGT
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入 CDS FASTA | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 FASTA 格式的核酸序列。 |
| `threads` 线程数 | 否 | 0 | 大文件保留 `0` 自动选择；需要固定顺序或小文件时可用 `1`。 0 对大型文件自动选择；1 关闭并行记录处理。 |
| `frame` 读码框 | 否 | 1 | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 从第 1、2 或 3 个碱基开始翻译。 |
| `geneticCode` 遗传密码表 | 否 | 1 | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 NCBI 翻译表代码。 |
| `trimTrailingStop` 移除末尾终止符 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 删除每条翻译序列末尾的一个“*”。 |
| `output` 输出蛋白 FASTA | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有的自定义输出文件。 |

## 结果怎么读

- 输出格式：`FASTA`
- 输出为蛋白 FASTA；先确认 CDS 起始帧、遗传密码、终止密码子和长度是否为 3 的倍数。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。
- 线程数只影响执行路径和速度；改变线程不应改变科学结果。发现差异时应比较日志、输入和参数。

## 最小运行示例

```powershell
opentools run fasta.translate-cds --param input=C:\data\input.fasta
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- FASTA/FASTQ 记录、ID 和碱基/质量字符必须完整；损坏或截断的记录会使任务失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
