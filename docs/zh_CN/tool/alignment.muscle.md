# MUSCLE 多序列比对

`alignment.muscle` · 比对 · v1.0.0

## 一句话说明

不经 shell，对本地 FASTA 运行 MUSCLE 5 或 MUSCLE 3。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 执行局部比对、多序列比对、系统发育建模或整理这些程序的输出。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`FASTA`
- 必须提供：`input`
- 确认查询/主体序列类型和格式正确；外部程序工具应检查可执行文件、版本、线程和超时。

### 格式示意

**input**

```text
>seq1
ATGCGTACGT
>seq2
ATGCGTTCGT
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入 FASTA | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 未比对的 FASTA 序列。 |
| `version` MUSCLE 版本 | 否 | MUSCLE5 | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 命令行语法版本。 |
| `threads` 线程数 | 否 | 4 | 默认值已按外部程序配置；仅在 CPU、内存或调度策略明确允许时增加。 MUSCLE 工作线程数。 |
| `timeoutMinutes` 超时分钟数 | 否 | 60 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 命令最大运行时间。 |
| `executablePath` MUSCLE 可执行文件 | 否 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 可选的显式可执行文件路径。 |
| `output` 输出比对 | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `extraArgs` 额外 MUSCLE 参数 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 支持引号的额外 CLI 参数。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`FASTA alignment`
- 输出为多序列比对；检查行数、序列名和对齐长度，错误输入字母或过短序列会影响结果。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。
- 线程数只影响执行路径和速度；改变线程不应改变科学结果。发现差异时应比较日志、输入和参数。

## 最小运行示例

```powershell
opentools run alignment.muscle --param input=C:\data\input.fasta
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 外部程序的版本和参数会改变命中、比对或树；发表时记录程序版本和完整命令。
- `extraArgs` 不能覆盖输入、输出、数据库、远程模式或线程数；只允许算法调优选项，并拒绝 `@` 响应文件和 `--`。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
