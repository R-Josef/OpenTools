# 查找 GFF3/GTF 重叠

`gxf.overlap` · 基因组注释 · v1.4.0

## 一句话说明

按序列分类并排序扫描，报告重叠的注释区间。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 检查或改写基因组注释，并验证序列名、坐标和 feature 关系。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`GFF3`、`GTF`、`GFF3.gz`、`GTF.gz`
- 必须提供：`input`
- 确认序列名与基因组一致；GFF3/GTF 坐标按 1-based inclusive 理解，BED 按 0-based half-open 理解。

### 格式示意

**input**

```text
##gff-version 3
chr1	OpenTools	gene	1	100	.	+	.	ID=gene1
chr1	OpenTools	mRNA	1	100	.	+	.	ID=tx1;Parent=gene1
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入注释 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 GFF3 或 GTF。 |
| `minOverlap` 最小重叠 | 否 | 1 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 最小重叠碱基数。 |
| `sameTypeOnly` 仅相同类型 | 否 | false | 从默认值开始；只有在理解上方说明后才改变。 仅比较相同 feature 类型的记录。 |
| `overlapMode` 重叠模式 | 否 | AUTO | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 AUTO 对大型注释落盘或在 maxRecords 时回退磁盘；DISK 始终使用临时 SQLite 索引。 |
| `maxRecords` 最大记录数 | 否 | 2000000 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 内存重叠路径驻留记录数的安全上限。 |
| `maxActiveRecords` 磁盘扫描最大活跃记录数 | 否 | 2000000 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 磁盘扫描同时保留的重叠记录数安全上限。 |
| `maxTempMegabytes` 临时 SQLite 最大容量 | 否 | 8192 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 DISK/AUTO 模式的临时磁盘安全上限（MiB）；0 表示不设显式上限。 |
| `maxPairs` 最大重叠对 | 否 | 100000 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 限制报告的重叠对数量。 |
| `output` 重叠报告 | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有报告。 |

## 结果怎么读

- 输出格式：`TSV`
- 输出为重叠区间对；检查最小重叠长度、feature type、方向与报告上限，避免把截断当成完整结果。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run gxf.overlap --param input=C:\data\input.gff3
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 未知序列、反向坐标、超出基因组长度和父子 feature 缺失都应在下游解释前检查。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
