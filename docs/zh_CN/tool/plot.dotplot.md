# 点图

`plot.dotplot` · 可视化 · v1.1.0

## 一句话说明

把数值坐标或 BLAST outfmt 6 的 HSP 绘制为基因组位置点图。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 把已经校验的数值表转换为用于检查或发表的图像，同时保留可追踪的数据路径。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`TSV`、`CSV`
- 必须提供：`input`
- 确认表头、数值列和缺失值符合参数要求；先检查输入表，再为图像解释负责。

### 格式示意

```text
x	y	group
1.0	2.1	control
1.8	3.0	control
2.2	4.4	treatment
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 点图表格 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 含 x/y 列的表格，或含 qseqid、sseqid、pident、qstart、qend、sstart、send 的 BLAST outfmt 6 表。 |
| `inputFormat` 输入格式 | 否 | AUTO | AUTO 通过 qseqid/sseqid 表头识别 BLAST outfmt 6；表头有歧义时显式选择。 |
| `queryLengthColumn` Query 长度列 | 否 | qlen | BLAST 输入可选的 qlen 列；缺失时由 qstart/qend 推导。 |
| `subjectLengthColumn` Subject 长度列 | 否 | slen | BLAST 输入可选的 slen 列；缺失时由 sstart/send 推导。 |
| `maxHits` 最大 HSP 数 | 否 | 5000 | 最多绘制的 BLAST HSP 行数；图过于密集时可调小。 |
| `xColumn` X 列 | 否 | x | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 数值 X 列。 |
| `yColumn` Y 列 | 否 | y | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 数值 Y 列。 |
| `groupColumn` 分组列 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选的系列分组列。 |
| `title` 图标题 | 否 | Dot Plot | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 图形标题。 |
| `subtitle` 图副标题 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选副标题。 |
| `valueLabel` 数值轴标签 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 Y 轴数值标签。 |
| `width` 图像宽度 | 否 | 1200 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 导出宽度，单位像素。 |
| `height` 图像高度 | 否 | 800 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 导出高度，单位像素。 |
| `dpi` PDF DPI | 否 | 144 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 PDF 导出分辨率。 |
| `exportFormats` 导出格式 | 否 | PNG_SVG_PDF | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 图形产物格式。 |
| `output` 输出前缀 | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`PNG`、`SVG`、`PDF`、`JSON`
- 表格模式下每个点来自一对 x/y 数值；先确认坐标单位和点的分组，再寻找趋势或异常。
- BLAST 模式下每条线段连接一个 HSP 在 query/subject 坐标中的起点和终点，颜色按一致性分组。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。
- 若输出了数据表，应同时核对图中点、组别、排序和筛选是否与数据一致。

## 最小运行示例

```powershell
opentools run plot.dotplot --param input=C:\data\input.tsv
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 空数据、全为缺失值、非数值列或阈值两侧没有数据时，图可能为空或无法解释。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
