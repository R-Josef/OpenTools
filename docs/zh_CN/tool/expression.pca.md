# 表达 PCA

`expression.pca` · 表达 · v1.0.0

## 一句话说明

计算样本主成分。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 对表达矩阵或功能注释做探索性统计，生成可继续绘图和人工审核的结果表。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`Expression matrix`
- 必须提供：`input`
- 确认输入格式、ID、表头和坐标约定与参数描述一致，并保留原始文件。

### 格式示意

```text
gene	sample1	sample2	sample3
gene1	12	18	15
gene2	40	36	44
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 表达矩阵 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 第一列为基因名的分隔文本矩阵。 |
| `groups` 样本分组 | 否 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 可选的样本/分组文件。 |
| `components` 主成分数 | 否 | 2 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 最多输出的主成分数。 |
| `delimiter` 分隔符 | 否 | AUTO | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 矩阵分隔符。 |
| `scale` 特征标准化 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 按标准差缩放基因。 |
| `log2` Log2 变换输入 | 否 | false | 从默认值开始；只有在理解上方说明后才改变。 PCA 前应用 log2(x+1)。 |
| `output` 输出坐标 | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`TSV`
- 输出解释方差和样本坐标；PC1/PC2 通常用于探索分组，但不能单独证明因果关系或显著差异。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run expression.pca --param input=C:\data\input.tsv
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 格式、列名、坐标或资源版本不匹配时，任务会在发布输出前失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
