# 拆分 FASTQ 文件

`fastq.split` · 序列 · v1.0.0

## 一句话说明

按固定记录数拆分 FASTQ 文件，并保留序列与质量值。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 在组装、注释、比对或下游分析前检查、转换或整理 FASTA/FASTQ 数据。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`FASTQ`、`FASTQ.gz`
- 必须提供：`input`, `recordsPerFile`
- 确认序列 ID 不重复、FASTA/FASTQ 记录完整；gzip 文件应保持原始记录格式。

### 格式示意

**input**

```text
@read1
ACGTACGT
+
IIIIIIII
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入 FASTQ | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 FASTQ，可选 gzip 压缩。 |
| `recordsPerFile` 每个文件的记录数 | 是 | 1000 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 每个输出文件中包含的 FASTQ 记录数。 |
| `outputDirectory` 输出目录 | 否 | 空 | 选择可写目录；批量输出前确认磁盘空间和命名冲突。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有分片文件。 |

## 结果怎么读

- 输出格式：`FASTQ`
- 输出目录包含按记录数切分的 FASTQ；检查记录总数、header、序列和质量值的完整性。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run fastq.split --param input=C:\data\input.fastq --param recordsPerFile=1000
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- FASTA/FASTQ 记录、ID 和碱基/质量字符必须完整；损坏或截断的记录会使任务失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
