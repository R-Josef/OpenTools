# 预览分隔文本表格

`table.preview` · 表格 · v1.1.0

## 一句话说明

流式读取大型 TSV 或 CSV（含引号跨行字段）并生成有界预览。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 整理实验表、注释表或统计结果，使列名和行结构适合后续分析。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`TSV`、`CSV`、`TSV.gz`、`CSV.gz`
- 必须提供：`input`
- 确认第一行是唯一表头，列名与参数一致；CSV 引号和分隔符必须合法。

### 格式示意

**input**

```text
group	value
control	1.2
treatment	2.4
```

## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入表格 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 可选用 gzip 压缩的分隔文本文件。 |
| `delimiter` 分隔符 | 否 | AUTO | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 AUTO 会检测 Tab、逗号或分号。 |
| `firstRowHeader` 首行是表头 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 将第一行作为列名。 |
| `previewRows` 预览行数 | 否 | 100 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 交互结果中最多保留的行数。 |
| `maxColumns` 最大列数 | 否 | 200 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 预览中包含的最大列数。 |
| `countRows` 统计全部行 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 读取完整文件并报告总行数。 |
| `output` 预览 TSV | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有的自定义输出文件。 |

## 结果怎么读

- 输出格式：`TSV`
- 预览表和行列计数用于快速检查文件结构；`countRows=false` 时总行数可能只是预览范围。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run table.preview --param input=C:\data\input.tsv
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 重复列名、缺失表头、空键和不可解析数值会导致校验或运行失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
