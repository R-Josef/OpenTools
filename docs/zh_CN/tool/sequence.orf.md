# ORF 预测

`sequence.orf` · 序列 · v1.2.0

## 一句话说明

使用可配置 NCBI 遗传密码表，在三个正向和可选三个反向读框查找 ORF。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 在组装、注释、比对或下游分析前检查、转换或整理 FASTA/FASTQ 数据。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`FASTA`、`FASTA.gz`
- 必须提供：`input`
- 确认序列 ID 不重复、FASTA/FASTQ 记录完整；gzip 文件应保持原始记录格式。

### 格式示意

**input**

```text
>seq1
ATGCGTACGT
>seq2
ATGCGTTCGT
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入 FASTA | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 核酸 FASTA。 |
| `threads` 线程数 | 否 | 0 | 大文件保留 `0` 自动选择；需要固定顺序或小文件时可用 `1`。 0 对大型文件自动选择；1 关闭并行记录处理。 |
| `minAminoAcids` 最小氨基酸数 | 否 | 30 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 ORF 最小长度。 |
| `geneticCode` 遗传密码表 | 否 | 1 | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 用于判断终止密码子的 NCBI 翻译表代码。 |
| `startCodons` 起始密码子 | 否 | ATG | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 逗号或空白分隔的密码子。 |
| `bothStrands` 双链扫描 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 扫描反向互补读框。 |
| `includePartial` 包含不完整 ORF | 否 | false | 从默认值开始；只有在理解上方说明后才改变。 包含无终止密码子的起点到末端 ORF。 |
| `output` 输出 ORF FASTA | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录；.gz 启用 gzip。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`FASTA`、`FASTA.gz`
- 输出为预测 ORF 的核苷酸序列；检查遗传密码、起始密码子、最小长度、链方向和部分 ORF 选项。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。
- 线程数只影响执行路径和速度；改变线程不应改变科学结果。发现差异时应比较日志、输入和参数。

## 最小运行示例

```powershell
opentools run sequence.orf --param input=C:\data\input.fasta
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- FASTA/FASTQ 记录、ID 和碱基/质量字符必须完整；损坏或截断的记录会使任务失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
