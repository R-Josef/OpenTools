# 连接表格

`table.join` · 表格 · v1.1.0

## 一句话说明

以有界右键索引流式连接左表，支持复合键和 INNER/LEFT/RIGHT/FULL。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 整理实验表、注释表或统计结果，使列名和行结构适合后续分析。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`TSV`、`CSV`
- 必须提供：`left`, `right`
- 确认第一行是唯一表头，列名与参数一致；CSV 引号和分隔符必须合法。

### 格式示意

**left**

```text
group	value
control	1.2
treatment	2.4
```

**right**

```text
group	value
control	1.2
treatment	2.4
```

## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `left` 左表 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 带表头的分隔文本。 |
| `right` 右表 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 带表头的分隔文本。 |
| `leftKey` 左键 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 一个或多个逗号分隔的左表连接列。 |
| `rightKey` 右键 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 一个或多个逗号分隔的右表连接列。 |
| `joinType` 连接类型 | 否 | INNER | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 INNER、LEFT、RIGHT 或 FULL。 |
| `maxRightRows` 最大右表行数 | 否 | 2000000 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 内存右键索引的安全上限。 |
| `delimiter` 分隔符 | 否 | AUTO | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 输入表格分隔符。 |
| `output` 输出表格 | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`TSV`
- 输出列由左右表拼接生成；检查 join type、键重复导致的行数扩张、空键和缺失值。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run table.join --param left=C:\data\left.tsv --param right=C:\data\right.tsv
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 重复列名、缺失表头、空键和不可解析数值会导致校验或运行失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
