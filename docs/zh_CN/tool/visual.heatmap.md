# 热图

`visual.heatmap` · 可视化 · v1.2.0

## 一句话说明

从带行列标签的数值矩阵生成可复现热图，包含诊断、排序和无界面导出。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 把已经校验的数值表转换为用于检查或发表的图像，同时保留可追踪的数据路径。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`TSV`、`CSV`、`TSV.gz`、`CSV.gz`
- 必须提供：`input`
- 确认表头、数值列和缺失值符合参数要求；先检查输入表，再为图像解释负责。

### 格式示意

```text
gene	sample1	sample2	sample3
gene1	12	18	15
gene2	40	36	44
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入矩阵 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 带表头和行名标签列的数值矩阵。 |
| `delimiter` 分隔符 | 否 | AUTO | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 AUTO 会检测 Tab、逗号或分号。 |
| `missingPolicy` 缺失值 | 否 | ROW_MEAN | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 选择缺失值报错、按行均值填充、填零或保留灰色。 |
| `invalidPolicy` 非法值 | 否 | AS_MISSING | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 选择非数值单元格是否终止工具执行或按缺失处理。 |
| `normalization` 数值标准化 | 否 | NONE | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 可选的逐行 z-score。 |
| `rowOrder` 行顺序 | 否 | ORIGINAL | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 使用输入顺序、行名、行均值或确定性平均链接层次聚类。 |
| `columnOrder` 列顺序 | 否 | ORIGINAL | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 使用输入顺序、列名、列均值或确定性平均链接层次聚类。 |
| `palette` 颜色映射 | 否 | BLUE_WHITE_RED | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 选择热图渐变色带。 |

| `rangeMax` 固定最大值 | 否 | 1.0 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 FIXED 颜色范围的上限。 |
| `title` 图标题 | 否 | OpenTools Heatmap | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选的图形模型标题。 |
| `subtitle` 图副标题 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选的图形模型副标题。 |
| `maxRows` 预览行数 | 否 | 200 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 序列化图形模型中保留的最大行数。 |

| `maxClusterItems` 最大聚类项数 | 否 | 1000 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 参与行或列层次聚类的项目数安全上限。 |

| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有的自定义输出文件。 |

## 结果怎么读

- 输出格式：`SVG`、`PNG`、`PDF`、`JSON`
- 热图展示处理后的矩阵；检查行/列排序、聚类、缺失值和色标范围，并用导出数据解释颜色。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。
- 若输出了数据表，应同时核对图中点、组别、排序和筛选是否与数据一致。

## 最小运行示例

```powershell
opentools run visual.heatmap --param input=C:\data\input.tsv
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 空数据、全为缺失值、非数值列或阈值两侧没有数据时，图可能为空或无法解释。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
