# SSR 挖掘

`sequence.ssr` · 序列 · v1.0.0

## 一句话说明

在 FASTA 序列中查找完美型简单重复序列（微卫星）。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 在组装、注释、比对或下游分析前检查、转换或整理 FASTA/FASTQ 数据。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`FASTA`
- 必须提供：`input`
- 确认序列 ID 不重复、FASTA/FASTQ 记录完整；gzip 文件应保持原始记录格式。

### 格式示意

**input**

```text
>seq1
ATGCGTACGT
>seq2
ATGCGTTCGT
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入 FASTA | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 核酸 FASTA，可选用 gzip 压缩。 |
| `maxMotifLength` 最大 motif 长度 | 否 | 6 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 检查 1 到该值的所有 motif 长度。 |
| `minRepeats` 最小重复次数 | 否 | 3 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 连续 motif 拷贝的最小次数。 |
| `maxLoci` 最大位点数 | 否 | 100000 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 达到该位点数后停止，并把结果标记为截断。 |
| `output` 输出 TSV | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`TSV`
- 结果取决于所选输入和参数；检查输出文件、摘要指标和诊断信息是否与实验设计一致。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run sequence.ssr --param input=C:\data\input.fasta
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- FASTA/FASTQ 记录、ID 和碱基/质量字符必须完整；损坏或截断的记录会使任务失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
