# 编辑 GFF3/GTF

`gxf.edit` · 基因组注释 · v1.0.0

## 一句话说明

编辑 source、type、strand 和属性，同时保留注释头。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 检查或改写基因组注释，并验证序列名、坐标和 feature 关系。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`GFF3`、`GTF`、`GFF3.gz`、`GTF.gz`
- 必须提供：`input`
- 确认序列名与基因组一致；GFF3/GTF 坐标按 1-based inclusive 理解，BED 按 0-based half-open 理解。

### 格式示意

**input**

```text
##gff-version 3
chr1	OpenTools	gene	1	100	.	+	.	ID=gene1
chr1	OpenTools	mRNA	1	100	.	+	.	ID=tx1;Parent=gene1
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入注释 | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 GFF3 或 GTF，可选 gzip 压缩。 |
| `setType` 设置 feature 类型 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 非空时替换第 3 列。 |
| `setSource` 设置 source | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 非空时替换第 2 列。 |
| `setStrand` 设置链方向 | 否 | KEEP | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 替换第 7 列或保持不变。 |
| `addAttribute` 添加属性 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 可选的 GFF3 key=value 或 GTF key/value 属性。 |
| `removeAttributes` 移除属性 | 否 | 空字符串 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 逗号分隔的属性键。 |
| `output` 输出注释 | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`GFF3`、`GTF`
- 编辑会保留注释头并改写数据行；检查 source/type/strand、属性增删和 GTF 引号格式。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run gxf.edit --param input=C:\data\input.gff3
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 未知序列、反向坐标、超出基因组长度和父子 feature 缺失都应在下游解释前检查。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
