# 过滤 VCF

`hts.vcf.filter` · 高通量测序 · v1.3.0

## 一句话说明

按质量、缺失、变异类型和双等位状态过滤 VCF/BCF。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 统计或筛选 SAM/BAM/CRAM、BED 与 VCF/BCF 数据，为质控和结果核查提供可追踪记录。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`VCF`、`VCF.gz`、`BCF`
- 必须提供：`input`
- CRAM 可能还需要参考 FASTA；有索引的 BAM/CRAM 更适合区域访问，VCF/BCF 应保持排序和有效头信息。

### 格式示意

**input**

```text
##fileformat=VCFv4.2
#CHROM	POS	ID	REF	ALT	QUAL	FILTER	INFO
chr1	10	.	A	G	50	PASS	.
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入 VCF/BCF | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 输入变异。 |
| `variantType` 变异类型 | 否 | ALL | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 变异类别过滤。 |
| `minQual` 最小 QUAL | 否 | 0.0 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 最小 Phred QUAL。 |
| `maxMissing` 最大缺失比例 | 否 | 1.0 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 最大 no-call 基因型比例。 |
| `biallelicOnly` 仅双等位 | 否 | false | 从默认值开始；只有在理解上方说明后才改变。 仅保留双等位位点。 |
| `threads` 线程数 | 否 | 0 | 大文件保留 `0` 自动选择；需要固定顺序或小文件时可用 `1`。 0 对大型文件自动选择；1 关闭并行变异判断。 |
| `indexType` 输出索引 | 否 | AUTO | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 AUTO 为压缩 VCF 写 TBI、为 BCF 写 CSI；NONE 禁用索引创建。 |
| `output` 输出 VCF | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`VCF`、`VCF.gz`、`BCF`
- 输出为筛选后的 VCF/BCF；检查记录数、INFO/FORMAT 字段、压缩格式和索引是否与下游工具匹配。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。
- 线程数只影响执行路径和速度；改变线程不应改变科学结果。发现差异时应比较日志、输入和参数。

## 最小运行示例

```powershell
opentools run hts.vcf.filter --param input=C:\data\input.tsv
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 确认排序、索引、参考基因组版本和序列字典一致；未排序或版本不匹配会产生错误或误导性结果。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
