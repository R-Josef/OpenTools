# 按 ID 提取 FASTA

`fasta.extract` · 序列 · v1.0.0

## 一句话说明

根据 ID 列表提取完整 FASTA 记录。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 在组装、注释、比对或下游分析前检查、转换或整理 FASTA/FASTQ 数据。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`FASTA`、`FASTA.gz`、`Text ID list`
- 必须提供：`input`, `ids`
- 确认序列 ID 不重复、FASTA/FASTQ 记录完整；gzip 文件应保持原始记录格式。

### 格式示意

**input**

```text
>seq1
ATGCGTACGT
>seq2
ATGCGTTCGT
```


**ids**

```text
seq1
seq2
```


## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `input` 输入 FASTA | 是 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 要检索的 FASTA 文件。 |
| `ids` ID 列表 | 是 | 空 | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 每行一个序列 ID，以 # 开头的行会被忽略。 |
| `matchMode` 匹配方式 | 否 | ID_TOKEN | 优先使用默认模式；只有输入类型或分析目标明确要求时才切换。 选择 ID 与 FASTA 标题的比较方式。 |
| `ignoreCase` 忽略大小写 | 否 | true | 从默认值开始；只有在理解上方说明后才改变。 比较 ID 时不区分大小写。 |
| `output` 输出 FASTA | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有的自定义输出文件。 |

## 结果怎么读

- 输出格式：`FASTA`、`Text`
- 输出只包含匹配的完整 FASTA 记录；报告中未命中的 ID 应被视为请求失败或命名不一致。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run fasta.extract --param input=C:\data\input.fasta --param ids=seq1
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- FASTA/FASTQ 记录、ID 和碱基/质量字符必须完整；损坏或截断的记录会使任务失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
