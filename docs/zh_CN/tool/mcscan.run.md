# 运行 MCScanX

`mcscan.run` · 比较基因组 · v1.0.0

## 一句话说明

对准备好的 .gff/.blast 文件运行本地 MCScanX。

它完成一个明确、可复现的分析步骤。运行记录会保存规范化参数、输入文件哈希和日志；正式发表前仍应检查原始数据、参数和生物学解释。

## 什么时候使用

- 准备、运行或整理共线性与 Ka/Ks 等比较基因组分析。
- 需要对单一步骤保留参数、日志和输出，便于重复运行或排查问题时。

## 输入准备

- 声明格式：`MCScanX inputs`
- 该工具没有必填参数；仍应确认数据集、路径和运行环境。
- 确认输入格式、ID、表头和坐标约定与参数描述一致，并保留原始文件。

## 推荐运行步骤

1. 先确认文件格式、序列名/列名和坐标约定一致。
2. 使用默认值或下表中的推荐值运行校验，先排除路径、表头和类型错误。
3. 提交任务后同时检查摘要、结果表和输出文件；不要只看“成功”状态。
4. 如需复现，保留原始输入、参数、运行日志和输出哈希。

## 参数怎么选

| 参数 | 必填 | 默认值 | 选择建议 |
| --- | --- | --- | --- |
| `prefix` 输入前缀 | 否 | mcscan | 可选项通常先留空；填写时保持 ID、列名或语法与输入一致。 匹配 .gff 和 .blast 文件的前缀。 |
| `timeoutMinutes` 超时分钟数 | 否 | 60 | 先使用默认值；调整阈值时记录理由，并与输入数据规模或统计目标对应。 最大运行时间。 |
| `executablePath` MCScanX 可执行文件 | 否 | 空 | 选择真实且完整的输入文件，不用示例占位路径替代。 可选的显式可执行文件。 |
| `output` 输出共线性 | 否 | 空 | 留空时写入运行目录；自定义路径应位于工作区，并按格式填写扩展名。 留空时保存到本次运行目录。 |
| `overwrite` 覆盖输出 | 否 | false | 默认 `false`；只有确认目标文件可替换时才设为 `true`。 允许替换已有输出。 |

## 结果怎么读

- 输出格式：`collinearity`
- 输出 MCScanX 共线性结果；检查 .gff/.blast 配对、程序版本、内存、超时和 block 结果。
- 结果面板是快速检查入口；完整数据、运行清单和日志位于本次运行目录。

## 最小运行示例

```powershell
opentools run mcscan.run
```

把占位路径替换为工作区中的真实文件。参数名必须保持原样，布尔值使用 `true` 或 `false`。

## 检查清单与失败边界

- 格式、列名、坐标或资源版本不匹配时，任务会在发布输出前失败。
- 已有输出默认不会被覆盖；只有明确设置输出路径并接受覆盖时，才检查 `overwrite`。
