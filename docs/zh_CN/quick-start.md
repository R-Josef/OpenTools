# 快速开始

## 1. 选择运行方式

Windows 用户优先使用便携整合包并双击 `OpenTools.exe`。开发者或已有 Java 21
环境时，可使用通用 JAR。不要在同一目录中混放不同版本的 `runtime/`、`app/` 和
`tools/`。

## 2. 建立项目

OpenTools 第一次启动会打开默认本地项目，也可以新建项目。项目目录保存：

- `project.json`：项目元数据；
- `.opentools/project.db`：作业历史；
- `data/`：建议的用户数据；
- `runs/`：每次运行的参数、清单、日志和输出；
- `results/`：可复用结果。

切换项目前应等待排队和运行中的作业结束。

## 3. 找到工具

从 Home 点击 **打开工具目录**，或直接进入 Tools。左侧工具按类别分组，支持
跨分类搜索。选择工具后，右侧表单会显示必填参数、可选参数和高级参数。

## 4. 校验并运行

1. 选择输入文件。
2. 检查自动推荐的格式。
3. 设置工具参数。留空输出通常表示保存到本次运行目录。
4. 点击**校验**，修正错误和警告。
5. 点击**运行**。工具在后台执行，可在 Jobs 和 Results 查看。

默认不覆盖已有输出。需要覆盖时，应明确确认并确认目标文件。

## 5. 查看结果

Results 页面显示摘要、表格或交互图形。每次运行的 `manifest.json` 保存输入哈希、
规范参数、工具版本、Java/操作系统信息和输出清单。失败时先查看结构化诊断，再
打开 `run.log`。

## 6. 打开文档

左侧 `Docs` 是完整应用内文档。首页提供分类入口，左栏可滚动浏览全部类别和工具；
工具页始终按当前 Schema 生成参数参考。在设置页切换语言后，主窗口和 Docs 会按
新语言立即重建，不需要重启软件。
