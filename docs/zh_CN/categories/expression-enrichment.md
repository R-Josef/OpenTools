# 表达与富集

表达工具支持标准化、相关、PCA 和差异分析输入准备。富集工具支持离线 GO 层级、
超几何检验、Benjamini-Hochberg 校正和 KEGG。带版本的 GO/KEGG 资源包可一次导入，
之后按资源包 ID 复用。Bar/Bubble 图可作为结果查看或独立绘图工具。

## 注意事项

- 表达矩阵应有唯一行 ID 和可解析数值；
- 标准化为相对比较，不替代实验设计或批次校正；
- GO/KEGG 注释数据库版本会影响结果，应在项目中保留快照；
- KEGG 富集需要匹配的背景和用户提供的注释表；
- 多假设检验结果需要结合效应量和研究设计解释。

在应用内 Docs 中展开“表达与富集”可打开全部 8 个工具。
