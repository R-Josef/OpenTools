# 注释与 BED

注释任务覆盖 GFF3/GTF 检查、过滤、转换、重叠、代表转录本、ID 映射、合并拆分、
安全修复、基因密度和序列提取，以及 BED 统计和 BED/GFF 转换。Pfam 与 eggNOG
导入也在该类别。

## 注意事项

- GFF/GTF 与 BED 坐标语义不同；
- 基因组和注释的序列名、长度、strand 需要一致；
- promoter 与上下游按转录本方向和 1-based inclusive 坐标计算；
- 密集区间和磁盘 spool 模式需要足够临时空间；
- 安全修复只处理可确定问题，不补造缺失业务注释。

在应用内 Docs 中展开“注释与 BED”可打开全部 15 个相关任务。
