# 可视化

可视化支持通用散点、折线、条形、堆叠条形、箱线、小提琴图，以及 PCA、相关热图、
火山图、序列 Logo、基因位置、结构域、Motif、Circos 和 eFP。Heatmap、Venn/UpSet
和基因结构任务也可直接输出绘图模型与图像。

## 注意事项

- 绘图输入通常是带表头的 TSV/CSV；列名必须匹配参数；
- 超大矩阵会使用有界显示抽样，完整导出仍以任务数据路径为准；
- PDF 中文依赖可嵌入字体，PNG/SVG 更适合通用交换；
- 聚类上限、最大交点数和图像尺寸都有 Schema 边界；
- 颜色和统计阈值是可复现参数，应随作业清单保存。

在应用内 Docs 中展开“可视化”可打开全部 20 个任务。
