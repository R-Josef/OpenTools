# Alignment and phylogeny

This category includes local and remote BLAST, DIAMOND, BLAST XML, FASTQ/region BLAST, HMMER,
MUSCLE, trimAl, Newick operations, IQ-TREE, MCScanX, and Ka/Ks.

## Cautions

- BLAST/DIAMOND/HMMER/MUSCLE/trimAl/IQ-TREE/MCScanX use external tools.
- Remote BLAST uploads the query to NCBI and runs only with allowUpload=true.
- Automatic BLAST program selection depends on query and subject molecule type.
- Choose E-value, maximum hits, threads, and timeout for the data scale.
- hmmscan requires a pressed HMM database and sidecars.
- Large phylogenies and alignments can run for a long time.
- MCScanX inputs need consistent gene/sequence coordinates and homology files.

The in-app Docs tree exposes all 18 related tools.
