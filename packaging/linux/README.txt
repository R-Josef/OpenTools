OpenTools Linux x64 portable package
====================================

1. Extract the complete tar.gz archive.
2. Run bin/OpenTools for the graphical interface.
3. Run bin/OpenToolsCLI in a terminal for CLI and MCP use.
4. Keep app/, lib/, runtime resources, tools/, docs/, and licenses/ together.

The package includes a private Java 21 runtime and pinned Linux x64 third-party
programs. Java and conda are not required.

OpenTools is GPL-3.0-or-later. Third-party programs retain their own licenses.
See licenses/ and THIRD_PARTY_NOTICES.md.
