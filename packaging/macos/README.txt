OpenTools macOS portable package
===============================

1. Extract the complete ZIP archive.
2. Open OpenTools.app for the graphical interface.
3. Run OpenTools.app/Contents/MacOS/OpenToolsCLI for CLI and MCP use.
4. Keep the complete application bundle and its tools/ and licenses/ together.

The package includes a private Java 21 runtime and pinned macOS third-party
programs for the architecture recorded in the release filename. Java and conda
are not required.

OpenTools is GPL-3.0-or-later. Third-party programs retain their own licenses.
The current snapshot release is unsigned. Organizations that enforce Gatekeeper
policy should use signed release credentials and a separate notarization step.
